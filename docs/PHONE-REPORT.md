## What the live tests found and fixed (v0.6.9 – v0.7.0)
- Deleting a project left it in everyone's list (the client kept asking for the deleted project); fixed on the server and the client.
- A friend invited to only that project stayed stuck on it, and their project list failed once they had no projects; fixed.
- The desktop app's logo was a window-drag area, so it didn't go Home there; fixed.
- The phone overview had lost its picture (hidden back when the top bar showed it); it's back, with a change badge.
- The calendar icon was blank on due dates and Upcoming (a missing icon name); fixed.

## Suggested next edits (phones)
1. **Long-press a message** on the phone for react, reply, pin, edit and delete in one sheet (today react/pin from the phone are quickest by the + menu or desktop).
2. **Offline drafts**: keep what you type in chat and notes when the host is unreachable and send it when it's back.
3. **Pinned messages** reachable from the Chat top bar (a pin icon with the count), not only the strip.
4. **Docs on phones**: open in reading mode with an Edit button, so scrolling a doc never opens the keyboard.
5. **Swipe a task slate** left to move it on (Backlog → In progress → Review → Done), right to move it back.
6. **Push notifications** check on real iPhones (Web Push needs the Home Screen app on iOS) and a test-notification button in Settings.
7. **Voice notes** transcribed by the host's local model when it runs, so they're searchable.
8. **Home rack**: a badge on Activity for things since your last visit.
