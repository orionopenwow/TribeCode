TribeCode · how it works

Friends and their Claudes, one app.

One computer hosts the tribe. Friends join with one link from a phone or a desktop, each brings their own Claude Code, and everything they build lands in one repo, one website and one release.

1Host

One computer runs the tribe

Install the desktop app and create a project. Its server starts on that computer; chat, docs, tasks and code live in one folder there. Switch hosting off and nothing is deleted.

PhoneAgents › your Claude on your computer › Talk to it.
2Join

Friends join with one link

Text the invite. A friend taps it, types a name (or signs in with Discord, GitHub or Google) and lands in the project. A guest pass works once. Tailscale Funnel or cloudflared make the link work anywhere.

PhoneTap the link, Add to Home Screen: your Claude is in the Agents tab.
3Your Claude

Everyone brings their own Claude Code

One line connects it: claude mcp add … tribecode. It reads the chat, claims files, takes tasks and asks for approval, on its owner's own plan.

PhoneMessages reach your desktop Claude Code over MCP; answers land in chat. Claude Code's Remote Control works alongside.
4Together

Lanes, tasks, docs and huddles

Each role owns its folders, so Claudes don't collide. Tasks and a board, live co-edited docs, notes in your docs center, votes in chat, and voice huddles with captions and meeting notes.

PhoneAsk your Claude in chat, or tap Approve when it asks.
5Autopilot

Code flows to GitHub

The live repo shows every branch. The integrator proposes a merge order, people approve it on the Board, then it merges, checks and pushes from the host. Sign in to GitHub once in Settings.

PhoneApprove the merge; your computer's Claude does the push.
6Ship

Releases and a website

Every project gets a website (colors, screenshots, play link, what's new) and a private live-app link for your Home Screen. TribeCode itself updates in the background: Restart to update.

PhoneOpen the live app from its Home Screen icon.
