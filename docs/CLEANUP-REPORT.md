# Cleanup report (2026-11-12, after v0.31.2)

A sweep for dead files, leftover agent artifacts and stale references. Only files with clear evidence of being unused were removed (git keeps their history). Everything uncertain is listed under "Ask Camp".

## How it was checked

- Every file under `scripts/`, `server/`, `app/ui/` and `templates/` was searched for by name (and by stem) in every other text file in the repo, ignoring `CHANGELOG.md`.
- Every `app/ui` script and stylesheet was checked against `app/ui/index.html` and the offline cache list in `app/ui/sw.js`, then against the other pages (`join.html`, `support.html`, …).
- Every `server/*.js` module was checked for a `require` from the server, scripts or tests.
- Every script and test path named in `package.json`, `.github/workflows/*`, the root `.bat` / `.command` files and `Tools/` was checked to exist.
- Tracked files were searched for agent leftovers: `.claude/`, worktrees, `*.orig`, `*.rej`, `*.bak`, `*.tmp`, logs, WIP or prompt dumps.
