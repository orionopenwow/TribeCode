# Run it as a company: Production

Checklists for a team that releases on a schedule. TribeCode keeps the records; legal and tax matters need a professional where you live.

## Organisation

- [ ] An org chart with one owner per seat and a stand-in for each
- [ ] A decision list: who decides product, money, hiring, release
- [ ] Onboarding page for new people and new AI helpers: goals, rules, where things are
- [ ] Access reviewed when someone joins or leaves

## Planning

- [ ] Company goals for the quarter, each with a number that shows progress
- [ ] A roadmap by milestone, reviewed monthly
- [ ] Capacity planned: people, AI helpers, and time for fixes
- [ ] Risks listed with an owner each

## Delivery

- [ ] Every change is a task with an owner, a reviewer and a definition of done
- [ ] A release calendar and a release owner per version
- [ ] Version numbers and change notes for every release
- [ ] A written review after anything goes wrong: what happened, what changes

## Quality

- [ ] Checklists per product type (see the website, game and app paths)
- [ ] Performance and accessibility budgets agreed and measured
- [ ] Brand kit: logo, colors, type, tone, used everywhere

## Money

- [ ] Every amount in and out recorded with a category and a document
- [ ] A monthly close: totals, runway, what changed
- [ ] Spending limits per seat; second approval above a set amount
- [ ] Contracts, invoices and licences filed in one place

## People and agreements

- [ ] Written agreements on pay, ownership of work, and confidentiality
- [ ] Contributor and licence terms for outside work and open source
- [ ] A fair way to raise and settle disagreements

## AI helpers

- [ ] Each helper has a role, limits, and a person who reviews its work
- [ ] What helpers may read and change is written down
- [ ] Nothing a helper proposes goes live without a person's approval
