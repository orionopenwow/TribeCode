# Motion graphics

**Motion Studio** makes short animations that loop perfectly: a UI reel for your app, a logo reveal, a launch clip for X, TikTok or Instagram, captions, lower thirds and end cards. Open it from **Design › Motion graphic**, or tell Flint "make a motion graphic".

## How it works

Every motion graphic is one shape that never cuts. It changes size, corners and colour from one **state** to the next, and its content swaps with a short blur. A cursor clicks and drags like a real person, the camera zooms so each state fills the frame, and the last frame is the first frame.

States sit on a **beat grid**. Something happens on every beat, so the timing feels musical even with no sound.

## Make one

1. Pick a template. There are more than 50, grouped as UI reels, app promos, logo reveals, kinetic type, stats, charts, social posts, product tours, end cards, transitions, lower thirds and captions.
2. Click a state on the timeline to change its words, size, colour or where the cursor clicks. Drag it along the timeline to move it to another beat.
3. Open **Feel** and pick one of more than 50 presets, like Crisp, Calm or Cinematic.
4. Open **Sound** to add a song you have the rights to. The studio finds its beat and snaps every state to it.
5. Open **Export** and choose MP4, WebM, GIF, a PNG frame, a web page, or **Put it on my website**.

## Tell Flint

These work with no AI:

| Say | What happens |
|---|---|
| "snappier", "calmer", "less bounce" | The springs change |
| "make it 9:16 for TikTok" | The size changes (also square, 16:9 and 4:5) |
| "sync it to the beat" | Every state moves onto the grid |
| "change the accent to teal" | The highlight colour changes |
| "add a toast", "remove the chart" | A state is added or removed |
| "export a GIF" | The file downloads |

For bigger changes, press **Have my AI do it**. Your own Claude Code, Codex or Gemini reads and saves the motion graphic through TribeCode's tools.

## Where it is saved

In a project, each motion graphic is a file in the project's `motion` folder, so everyone in the tribe sees the same one. Without a tribe, it stays on this device.
