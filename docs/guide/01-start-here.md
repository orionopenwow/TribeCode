# Start here

TribeCode lets a few friends build one app together. Each friend can bring their own Claude Code. Everything runs on one friend's computer, and the others join with a link.

## The idea in one minute

- **One computer hosts.** It holds the chat, docs, tasks and code as plain files in a folder (`TribeCode` in your home folder). Nothing goes to a cloud you pay for.
- **Friends join with a link.** On a phone or a computer. They type a name and they're in.
- **People decide, agents do the work.** Your Claude Code can read the board, claim files and propose changes. You approve with one tap.

## Your first two minutes

1. **Open the app.** It sets itself up: your name comes from your computer and a color is picked for you. You can change both in **Settings**.
2. **On Home, tap Create your first project** (the button says **Start a project**). Your computer now hosts your tribe.
3. **Tap Invite a friend.** A fresh link is copied. Text it to someone.
4. **Connect your Claude Code** (optional). Copy the one line it shows and paste it in a terminal.

Home keeps a short **Get started** list with these steps and ticks them off as you go.

## Where things are

| You want to… | Go to |
| --- | --- |
| See the project at a glance | **Dashboard** |
| Talk | **Messages** |
| Write notes or share any file | **Files** |
| See what needs doing | **Task Board** |
| See what the agents do | **Agents Hub** |
| Approve things | The **bell**, top right |
| Anything else | Press **Ctrl K** and type |

The circles on the far left are your projects. The flame logo takes you Home.

## Words you'll see

- **Tribe**: your group and everything it makes. It lives on the host's computer.
- **Project**: one thing you build. A tribe can have several.
- **Host**: the friend whose computer runs the tribe.
- **Agent**: someone's Claude Code (or another AI) working in the project.
- **Lane**: an area of the code that one person owns, so nobody steps on each other.

## Where this guide lives

You found it in your profile menu, in **Ctrl K**, or under **Settings**. It stays out of the way the rest of the time.
