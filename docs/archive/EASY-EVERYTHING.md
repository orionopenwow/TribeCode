# Easy everything: one tap for every part of TribeCode

The bar: Invite a friend is one tap and the link is copied. Signing in to GitHub, exporting to a Desktop folder,
adding a phone shortcut to the live app and the starter shelf are being brought to that bar now. This is the list
of everything else that should feel the same, grouped by where it lives. ✅ = works this way today.

## Getting in
- ✅ Invite a friend: one tap, fresh project, link copied (Home, rail +, Invite-A-Friend.bat).
- ✅ Join: tap the link, type a name. Phones get the app; computers get the one line for Claude Code.
- ✅ The host signs back in automatically on their own computer.
- Sign in to GitHub once in the app (device flow), and every project pushes by itself. *(building now)*
- **Bring a friend's whole team**: an invite that adds several people at once (a group link that names a role).
- **Rejoin anywhere**: "Send me a sign-in link" to your phone from the desktop, instead of a new invite.

## Starting and shaping a project
- ✅ Create my own, a template, Bring my code, Join (Discord-style); picture, name, bio; invite friends right after.
- ✅ Starter shelf: picks for the project type, skills copied into `.claude/skills`.
- **Import from GitHub by pasting the URL anywhere** (chat, Home, the rail): TribeCode offers to clone it as a project.
- **Duplicate a project** (as a template for the next one), with or without its chat.
- **Archive instead of delete**: hide a finished project, keep everything, bring it back in one tap.

## Working together
- ✅ Roles/lanes with folders; file claims; hand-offs; reviews; daily plan.
- **Claim a task by dragging it onto your face** in the room panel (and onto your Claude to delegate).
- **"Pair with me"**: one tap puts two people (or a person and a Claude) on the same task with a shared doc and a huddle.
- **Conflict fixer**: when two branches touch the same file, a card shows both changes side by side with "Keep mine / Keep theirs / Ask my Claude to merge".
- **Weekly recap** posted on Mondays: what shipped, who did what, what's next (local model, no Claude tokens).

## The repo and the app
- ✅ Autopilot to GitHub; Preview app; screenshots on the repo hero.
- Live preview on the phone's Home Screen; Desktop shortcut; Export to a Desktop folder / keep a copy there. *(building now)*
- Website for every project, rebuilt automatically, with suggested edits. *(building now)*
- **One-tap release**: "Ship v0.2" tags the repo, writes release notes from the gists, and posts the link.
- **Undo the last change**: one tap reverts the last commit on main (with a vote when others are in the project).
- **Share a build with someone outside the tribe**: a temporary public link to the preview (Tailscale Funnel), expires in a day.

## AI
- ✅ @ai for anyone (your Claude, a teammate's with their OK, the local model, or the board).
- ✅ Connect Claude Code in one line; Anywhere / Wi-Fi / This computer.
- **Install the local model in one tap**: the app downloads Ollama + a small model with progress, no terminal.
- **Agent budget**: each person sets "my Claude may spend up to N messages a day on friends' asks".
- **Explain this file**: long-press any file or doc for a plain-language summary from the local model.

## Phones
- ✅ Home first; rack per screen; slates; approvals; voice notes; Ask AI.
- **Long-press a message** for react, reply, pin, edit, delete. 
- **Offline drafts** that send when the host is back.
- **Share sheet target**: share a photo or link from any phone app straight into a project's chat or notes.

## Hosting
- QR pairing from a phone, a draft tribe on the phone, links that survive a move, move hosting in one tap, co-hosts with failover (docs/MOBILE-TRIBES.md).
- **Health card**: one glance at disk, backups, tunnel, updates, and a "Fix it" button for each.
- **Backups to GitHub**: an encrypted nightly backup of the tribe to a private repo, restored in one tap.

## Making it feel alive (lightly)
- Small matte emoji on a few internal labels (sections, helpers, toolbox kinds), never on the main icons.
- A short, friendly empty state with one action everywhere (no dead ends).
