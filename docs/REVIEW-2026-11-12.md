## Still open

- **Payments.** `PUT /api/premium` stands in for the webhook. TODO(payments): a signed Stripe/Paddle webhook calls the same `set` path, and checkout creates the session. Credit packs can't be bought yet.
- **Credit cost.** It is flat: 1 credit per hosted answer. Pricing by tokens or by model needs the hosted service's usage numbers.
- **Plan scope.** The plan is per tribe (one `.tribe/premium.json`). A per-account plan that follows a person across tribes waits on accounts moving beyond one host.
- **Site publish leftovers.** Publishing overwrites `site/`, but an asset removed from the design stays on disk. Each publish is bounded, but stale files are not cleaned up, because the folder can also hold hand-made files.
- **Screenshot screens.** Each screen keeps 60 versions, but the number of screens is not capped. Adding screens is rate-limited (the upload bucket).
- **Voice-note budget.** Reaching the budget refuses new voice notes. Nothing is removed automatically, and the host frees space by deleting captures.
- **8d** (above): the Rust loopback fallback for the desktop app.
- **Reverse route check** (from the 11-11 review): server routes that nothing calls are still not listed.
