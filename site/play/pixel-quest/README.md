# Pixel Quest

A TribeCode starter project: a tiny browser platformer with no build step.

Run it: open this folder with any static file server, then open `index.html`.

- `src/main.js`: the game loop (the world survives edits)
- `src/systems/*.js`: one mechanic per file (movement, combat, enemies, input)
- `src/art/draw.js`: everything you see
- `src/data/tuning.js`: game feel numbers
- `LANES.json`: who owns which files
- `CLAUDE.md`: how the agents work here
