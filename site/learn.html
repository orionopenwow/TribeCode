What code is

Code is a list of instructions for a computer, written in a language it can follow. Every app, game and website is made of it.

  1. Computers follow instructions exactly

    They don’t guess what you meant. “When someone taps Start, show level 1” has to be spelled out, step by step. That spelled-out version is code.

  2. Languages are just different ways to write those steps

    Like spoken languages, each has its own words and grammar. Some are best for web pages, some for phones, some for data. You can start with any of them.

  3. Code lives in files, and files live in folders

    A small website might be three files. A big game might be thousands. A project’s folder of code is called its code repository.

  4. AI helpers can write code for you

    Tools like Claude Code, Codex and Gemini CLI read your project and write code when you describe what you want in plain words. You still decide what to build and check that it works.

Your first app, step by step

The same six steps work for a game, an app, a website or a tool. In TribeCode, the Getting started checklist walks you through the first four.

  1. Write the idea down

    One or two sentences: what it is and who it’s for. “A recipe app for our family, so everyone can add their favorites.” This is your vision.

  2. Break it into small tasks

    “Show a list of recipes.” “Add a recipe.” “Search by name.” Small tasks are easier to finish and easier to share out.

  3. Connect an AI helper

    Give it one task at a time. It writes the code, runs it, and tells you what it changed.

  4. Try it in the preview

    Click around like a user would. If something looks wrong, say what you saw. Fixing is part of making.

  5. Save the change

    Each working step is saved in the code repository with a short note, so you can always go back.

  6. Share it

    Send friends a link, put the website online, or publish the app. Then start the next small task.

Building together without stepping on each other

When several people and their AI helpers work on one project, a few simple habits keep everyone’s work safe.

Code repository

One shared folder

Everyone works from the same code repository on GitHub, so nobody emails files around.

Saved changes

Small and often

Save a change each time something works, with a note saying what changed. The history shows who did what.

Branches

Your own copy to work in

A branch is a side copy where you try things. When it works, it’s merged back into the main version.

Your part

Claim an area

Say which files or features you’re working on. Your AI helper stays in that part, so changes don’t collide.

Review

A second pair of eyes

Before a change joins the main version, someone looks at it and approves. In TribeCode that’s one tap.

Kindness

Ask, don’t assume

Post what you’re doing, ask before changing someone else’s part, and thank people for reviews.

Languages, simply

You don’t have to pick one before you start. Your AI helper usually chooses a good fit for what you’re making, and you can learn the language as you go.

Websites

HTML and CSS

HTML says what’s on a page (a heading, a button). CSS says how it looks (colors, sizes, layout).

Deeper

Every web page is built on these two. They describe structure and style but don’t make decisions; that’s JavaScript’s job.

<button class="go">Start</button>
.go { background: orange; }
Websites and apps

JavaScript

Makes web pages do things: react to clicks, load data, run games in the browser.

Deeper

It runs in every web browser, and with Node.js it runs on servers too. TypeScript is JavaScript with labels for kinds of data, which catches mistakes early.

button.onclick = () => {
  score = score + 1;
};
Data, AI, tools

Python

Reads almost like English. Popular for data, AI, automation and first programs.

Deeper

Great for scripts that tidy files, analyze spreadsheets or talk to AI models. Also used for web servers and in many schools.

for name in friends:
    print("Hi", name)
iPhone and Mac apps

Swift

Apple’s language for apps on iPhone, iPad and Mac.

Deeper

SwiftUI lets you describe screens in a few lines. Publishing to the App Store needs a Mac and an Apple developer account.

Text("Hello, tribe!")
  .font(.title)
Android apps

Kotlin

Google’s recommended language for Android apps.

Deeper

Jetpack Compose describes screens in code, much like SwiftUI. Tools like React Native and Flutter can build for iPhone and Android from one codebase.

Text("Hello, tribe!")
Games

C# and GDScript

C# powers games made in Unity. GDScript is the simple built-in language of the free Godot engine.

Deeper

For small browser games, JavaScript with a library like Phaser works well. Game engines handle drawing, sound and physics so you can focus on play.

func _on_jump():
    velocity.y = -400
Saving data

SQL

Asks questions of a database: “show every recipe with chocolate in it.”

Deeper

Databases keep data safe and searchable even with millions of rows. SQLite is a tiny one that lives in a single file.

SELECT name FROM recipes
WHERE name LIKE '%chocolate%';
Fast and safe

Rust and Go

Languages for speedy programs and servers. TribeCode’s desktop app uses Rust.

Deeper

Rust prevents whole kinds of crashes before the program runs. Go is simple and popular for web services. Both are good second languages.

fn main() {
    println!("Hello, tribe!");
}
Glue

The terminal

A text window where you type commands instead of clicking. AI helpers like Claude Code run there.

Deeper

A few commands go a long way: cd moves between folders, ls (or dir) lists files, git status shows what changed.

cd my-game
git status

// words to know

Words to know

Code repository
The shared online folder that holds a project’s code and every saved change. Often on GitHub.
Saved change (commit)
A snapshot of the code with a short note about what changed.
Branch
A side copy of the code where you can try things without touching the main version.
Merge
Bringing the changes from a branch back into the main version.
AI helper (agent)
An AI tool that reads your project and writes code from plain-language requests.
Preview
A live view of your app that updates as the code changes.
Bug
Something that doesn’t work the way it should. Finding and fixing bugs is normal.
Open source
Code anyone can read, use and improve. TribeCode is open source under the MIT license.
