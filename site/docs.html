Start a Campfire Huddle

TribeCode is early. This page covers the basics; the full, current docs live in the README on GitHub.

1. Host a tribe

  1. Install the desktop app from GitHub Releases (Windows, macOS, Linux).
  2. Finish first-run setup: name, color, folder and (optionally) a local brain.
  3. Click Invite friends → Host a tribe on this computer. You become the host.

Prefer the terminal? With Node 20+:

npm start
# or: node server/index.js --port 4747 --dir ~/TribeCode --name "Campfire Crew"
# then open http://localhost:4747

2. Invite friends

Click Invite friends, pick how long the link lasts, how many people, and builder or spectator. Send the link or show the QR code. No accounts.

3. Connect your Claude Code

Click Connect your Claude Code in the room panel and run the command it shows:

claude mcp add --transport http tribecode http://HOST:4747/mcp --header "Authorization: Bearer <key>"

4. Join from a phone

Scan the invite QR code, pick a name, then use Share → Add to Home Screen. Outside your Wi-Fi, install Tailscale on both devices. Voice on a phone needs HTTPS (tailscale serve 4747).
