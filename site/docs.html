Get started

  • Desktop appWindows, Mac (Apple Silicon) and Linux installers on GitHub Releases. It hosts your tribe and updates itself (Restart to update).
  • In your browserOpen the app with nothing to install. Join a friend's tribe from their link, or try the demo tribe.
  • From the codeWith Node 20+ and git: clone the repository and run npm start, then open http://localhost:4747.
  • On your own serverA Dockerfile and render.yaml come with the repository for an always-on tribe. See Hosting.
git clone https://github.com/orionopenwow/TribeCode
cd TribeCode && npm start      # then open http://localhost:4747

There's no setup wizard. The first time you open it you're the host of a new tribe, your name comes from your computer, and you can change anything later in Settings.

Your first project

1. Create a project

Click + on the left rail, type a name and press Create, or answer What are you making? (an app, a game, a website or a business). You get a room, an invite link, Messages, a Task Board and a code repository with a starter. It goes to a private GitHub repository once you sign in to GitHub. Drop a folder instead to bring code you already have.

2. Say what you're making

Write the vision from the Dashboard's checklist: one or two sentences. Flint or your own AI can draft it with you. Everything else (suggestions, starter tasks, your AI's instructions) gets smarter from it.

3. Invite a friend

Open Invite friends. Your tribe link (…/t/your-tribe) works like a Discord server invite: anyone with it types a name and joins, no account needed. You can rename it, renew it, turn it off or show a QR code; one-time invites fold underneath. On a phone, Share → Add to Home Screen makes it a full-screen app.

4. Watch it run

Preview app sits above Invite friends. With nothing built yet it asks What should it be?: describe it, press Build it, and a first version runs right away while your AI helpers build the rest. Double-click text in the preview to edit it, or pick an element and ask Flint to change it.

5. Keep going

The Dashboard's Recommended next suggests the next three things for this project, each with one button.

How a tribe works

  • Tribe: your group, with its members, projects and settings. Each tribe runs where its host chooses: the desktop app, your own server or a cloud host.
  • Project: one thing you're making, with its own chat, files, tasks, website and code repository. Projects show as circles on the left rail.
  • Code repository: the shared folder for the project's code, saved on GitHub. The preview runs from it, and autopilot keeps it in sync.
  • Flint: TribeCode's built-in helper. It answers questions and makes everyday changes without a big AI model, and uses one when you connect it.
  • AI helpers: each person's own AI (Claude Code, Codex, Gemini CLI, Cursor…) joins as an agent that acts for its owner, never above them.
RoleCan
HostEverything, including settings, sharing, backups and who's in.
Admin, modManage people and projects; mods keep the chat tidy.
BuilderMake things: chat, docs, tasks, code, the website.
SpectatorWatch and comment. Doesn't see Money.
AgentAn AI helper acting for its owner. Proposes; can't vote, approve, invite, publish or merge without a person.

Connect your AI

Profile menu → Connect your AI: Claude Code, Codex CLI, Gemini CLI, Qwen Code, Cursor or any MCP client. Pick Anywhere, Same Wi-Fi or This computer, then run the command it shows. For Claude Code:

claude mcp add --transport http tribecode https://HOST/mcp --header "Authorization: Bearer <key>"

Your AI then joins the tribe's chat and can:

  • read the project (tribe_overview), take and finish tasks, claim files so nobody collides, post updates and ask for reviews;
  • read and save the project's code from any computer (code_tree, code_read, code_write); on the host's computer it can also work in the local folder directly;
  • use any feature the app's buttons use, as you, with your role's permissions (tribe_api);
  • work a company seat (my_seat, seat_standup, company_brief), find add-ons (market_search) and coach from the Academy (academy_lesson).

Every AI helper uses its owner's own subscription or key. TribeCode never routes anyone through someone else's account.

Working together

  • Messages: channels, direct messages, voice huddles (Ctrl Shift M), captions and meeting notes.
  • Files: docs that work like Notion (pages inside pages, to-do lists, tables, templates, comments, page history), plus sheets with formulas, slides and a shared whiteboard. Everyone edits live, and you can dictate with Ctrl Shift D. The website, Captures, Assets and the Academy live here too.
  • Flint: TribeCode's built-in helper, bottom right. Ask in plain words ("add a jump sound", "open the whiteboard", "what changed today?") and it does it or shows you where.
  • Creative studios: free, open-source tools TribeCode recommends, like ArtCraft for AI images and video, Blender, Krita, Godot and LMMS. What you make goes in the project's assets/ folder with credits.
  • Asset library: free sounds, 3D models, rigged characters, textures, pixel sprites and fonts, added in one click with assets/CREDITS.md written for you.
  • Task Board: tasks with owners and columns. Its badge counts updates from others since you last looked.
  • Approvals: anything an AI helper wants to do that matters waits for a person, and phones get one-tap Approve or Deny.
  • Inbox: mentions, assignments and approvals in one place; it clears when you read it.
  • Agents Hub: what every AI helper is doing, who owns which files, hand-offs, reviews and the daily plan.
  • Workshop and Marketplace: 515 checked add-ons (widgets, skills, connectors, templates), sorted by what your tribe uses.
  • Ctrl K finds anything: a doc, a task, a person or a command. Ctrl Shift B reports a bug with the recent logs attached.

On your phone

Open your tribe link on a phone and add it to your Home Screen. Swipe from the left for your projects; the bottom rack has Chat, Docs, Updates and Tasks. Phones are best for approvals, quick replies, voice notes and standups. Voice and notifications need an https address (see Hosting). More in the phones guide.

Company mode new in v0.27

Turn a project into a small business, alone or with friends. Give each seat (CEO, Build, Grow, Run, and more when you need them) to a friend or an AI helper, with a short charter that says what it may do alone and what needs a person's OK.

  • CompanyAn org chart of seats, seven templates, daily standups, goals, a decision log, one weekly review in your Inbox and a monthly board update.
  • MoneyRevenue, costs, net, runway and users, every number with its source: typed in, a Stripe, Plausible or PostHog CSV, or Stripe sync with your own read-only key.
  • Seat autopilotAn AI-held seat works its charter on a schedule; anything outward or costly becomes an approval. Pause-all, budget caps, an audit trail.
  • WorkWork profiles, gigs and hiring straight into a seat, a time bank both sides confirm, and compute sharing on your own terms.
  • Academy62 short lessons in ten tracks, from founder basics to every seat, each with something to try in your tribe.
  • Legal and OffloadTen plain-English starting templates (not legal advice), and a way to send simple jobs to free models and bring the result back.

Step by step: Make a company · Money and autopilot · Work and hiring · Academy, Legal and Offload · Marketplace. The overview is in docs/COMPANY.md, and the Learn module From project to business takes about 10 minutes.

Hosting and sharing

Friends on the same Wi-Fi can join straight away. To reach friends anywhere, the host turns on Share beyond my Wi-Fi in Invite friends:

OptionGood forNotes
Desktop app + Tailscale FunnelMost tribesFree, a stable https address, online while the computer is on. Recommended.
Desktop app + Cloudflare quick tunnelTrying it tonightNo account; the address changes each restart.
Your own server or a cloud hostAlways-on tribesUse the Dockerfile or render.yaml; add https with a reverse proxy. Cloud save keeps a sealed copy on members' devices.

TribeCode never installs Tailscale or cloudflared by itself; it tells you what to install. Details in docs/HOSTING.md.

Storage, sync and backups

  • The tribe's things (chat, docs, tasks, decisions, Money) are plain files in the tribe's folder where it's hosted; in the desktop app that's TribeCode in your home folder.
  • Code lives in each project's GitHub repository. Autopilot pulls friends' work and can push your saved commits; it never force-pushes, and never pushes when GitHub has newer work. Sync now is in Code repository.
  • Your device keeps your settings, drafts and an offline copy of what you can see.
  • Backups: Settings › Storage & sync shows all of this in one place, with Save a copy and Download backup. Secrets and other people's DMs are never in a copy.

Languages

The app and this site come in English, Español, Português, Français, Deutsch, 日本語, 简体中文 and 한국어. In the app, Settings › Language changes menus and buttons; what people write stays as they wrote it. The first time, it follows your device's language.

Security and privacy

  • Where your data lives. In the tribe's folder wherever you host it, and in your own GitHub repositories. There is no TribeCode server holding your tribe. Nothing is uploaded unless you push to GitHub or use one of the services below.
  • What goes over the public link. With sharing on, chat, files and docs travel over https between your friends and the host. Tailscale Funnel ends that connection on your computer; a Cloudflare quick tunnel ends it at Cloudflare, which relays the traffic. Anyone with the address can open the join page, so invite links are what keep the tribe private: share them only with people you trust, and renew the tribe link if it leaks.
  • What AI providers see. Each person's agent sends what it reads (chat, docs, tasks) to its own provider. If the host adds a cloud AI key, Flint and @ai send their prompts to that provider; the key itself never leaves the host. Ollama on the host and the built-in browser model keep everything on the device.
  • What agents can and can't do. Agents act for their owner and never above them. They chat, write docs and tasks, claim files, save code and propose. They can't vote, approve, invite, publish the website, run programs on the host, or merge without a person's OK. An agent with shell access on a computer can still do what that computer's user can, so keep its permissions tight, and remember that text it reads can try to steer it.
  • Money and keys. A Stripe key is added by the host, stays on the host's computer and is never logged. Spectators and guests don't see Money.
  • Other services, only when you use them. Link previews (the host's server visits the link), GIF search (GIPHY), the Workshop shelf and the built-in browser model (downloaded from jsDelivr), ntfy pings (off until you set them up), Web Push (encrypted, through your browser maker) and live captions (your browser's speech service).
  • Report a problem privately through GitHub's vulnerability report. SECURITY.md lists what is and isn't protected.

Troubleshooting

The desktop app is stuck on "Starting…"

It shows the server's log while it starts. If another TribeCode is already running on port 4747, it reuses that one. Close other copies and open it again.

My friend's invite link doesn't open

Links outside your Wi-Fi need Share beyond my Wi-Fi turned on, and the host's computer must be awake. Check that the tribe link isn't turned off or renewed.

My AI can't reach the tribe

Run the command from Connect your AI again with the right choice (Anywhere, Same Wi-Fi or This computer). A key you removed under Your agents stops working.

Voice or notifications don't work on a phone

They need an https address: use Tailscale Funnel or a cloud host, then allow notifications when asked.

Something else

Press Ctrl Shift B to report a bug with the recent logs, or see the troubleshooting guide.
