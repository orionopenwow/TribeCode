# Scene lane

Owned by **Scene**. `room.js` builds the tavern from simple shapes (floor, walls, bar, fireplace, stage,
kitchen hatch, tables, stools, barrels, lights) and returns colliders, named spots, seats and walkable points.
`palette.js` holds every color. Spot names and seat ids are a contract with the NPCs lane: rename one only after
an `upgrade` gist.
