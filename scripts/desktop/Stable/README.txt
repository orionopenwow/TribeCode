STABLE  (branch: main)
======================

Double-click Start-Stable.bat.

- Runs the released TribeCode from source at http://localhost:4747
- Uses your real tribe folder: %USERPROFILE%\TribeCode
- Same code as the installed app. If the app is already open, it just opens it.
- Only changes when a new version is released (then the app also shows
  "Restart to update").
