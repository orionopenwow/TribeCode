# Calculator

A clean calculator with brackets, percent and keyboard input, on a tiny safe parser (no eval). A base for unit, tip or loan calculators.

## Run it

Open `index.html` in a browser. No install, no build step.

**Controls:** Click the keys or type; Enter equals, Esc clears, Backspace deletes.

## Tweak it

Every knob is in `config.js`. Ask Flint ("Turn it into a tip splitter") or change a value and reload.

| Knob | What it does | Default |
| --- | --- | --- |
| `decimals` | Decimals to show | `10` |
| `accent` | Accent | `#F26B1D` |
| `bg` | Background | `#12151A` |
| `surface` | Cards | `#1B2028` |
| `ink` | Text | `#E7E9EE` |
| `muted` | Quiet text | `#94A3B8` |
| `line` | Lines | `#2A313C` |
