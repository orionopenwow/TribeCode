# Endless runner

Jump the obstacles as the world speeds up. One button, a best score, and room for power-ups, skins and levels.

## Run it

Open `index.html` in a browser. No install, no build step.

**Controls:** Space, Up or a tap to jump; hold for a higher jump.

## Tweak it

Every knob is in `config.js`. Ask Flint ("Make it floatier") or change a value and reload.

| Knob | What it does | Default |
| --- | --- | --- |
| `title` | Game title | `Endless runner` |
| `speed` | Start speed | `6` |
| `speedUp` | Speed-up per frame | `0.002` |
| `gravity` | Gravity | `0.7` |
| `jump` | Jump power | `12` |
| `gap` | Space between obstacles | `70` |
| `runner` | Runner color | `#F26B1D` |
| `obstacle` | Obstacle color | `#FF6F8E` |
| `sky` | Sky | `#1B2028` |
| `hills` | Hills | `#222833` |
| `ground` | Ground | `#2A313C` |
| `bg` | Page background | `#12151A` |
