# Top-down arena

Move, aim and shoot while waves of slimes close in. A twin-stick arena to grow into a dungeon crawler or a survivor game.

## Run it

Open `index.html` in a browser. No install, no build step.

**Controls:** WASD or arrows to move, aim with the mouse, click or hold Space to shoot. On a phone: drag to move, tap to shoot.

## Tweak it

Every knob is in `config.js`. Ask Flint ("Add a dash on Shift") or change a value and reload.

| Knob | What it does | Default |
| --- | --- | --- |
| `speed` | Hero speed | `3` |
| `hearts` | Hearts | `3` |
| `foeSpeed` | Slime speed | `1.2` |
| `foesPerWave` | Slimes in the first wave | `3` |
| `bulletSpeed` | Shot speed | `9` |
| `hero` | Hero color | `#F26B1D` |
| `foe` | Slime color | `#3BD16F` |
| `bullet` | Shot color | `#FABD2F` |
| `floor` | Floor | `#1B2028` |
| `grid` | Floor lines | `#222833` |
| `bg` | Page background | `#12151A` |
